Contractor Access Expiry

Find and review GitHub outside collaborators before their access becomes permanent.

Your identity provider offboards employees.
Nobody offboards contractors.
GitHub's SCIM provisioning manages organization members. Outside collaborators are not members, so they sit outside that lifecycle entirely — and on private or internal repositories, each one consumes a licensed seat for as long as the grant exists.

What it does

  • Inventories every outside collaborator across your repositories
  • Shows who has had no commit activity in {{ stale_days }}+ days
  • Estimates what those seats cost you per month
  • Lets you set a review interval for new grants

What it cannot do

It holds no write permissions. It cannot add, change, or remove access — there is no code path that does. Removing a collaborator from a private repository permanently deletes their private forks, so that decision stays with you, made deliberately in GitHub.

Install from the GitHub Marketplace to see your organization's report.
