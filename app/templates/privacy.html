We do not store who your collaborators are.
The report you see is computed live from GitHub each time you open it and is not retained. What we keep is counts and totals — how many people, how many flagged, what the estimate came to. Not names.

What the app reads

With the read-only permissions you granted at install, the app asks GitHub for:

  • the repositories the installation can see, and whether each is public, private, or internal
  • the outside collaborators on those repositories, and their permission level
  • the date of each collaborator's most recent commit to each repository
  • your organization's plan name, to pick the right per-seat rate

This data is used to build the report and then discarded. It is not written to disk, not logged, and not sent anywhere.

What the app stores

StoredWhy
Installation ID, organization login, account type, install and uninstall times To know the app is installed and to reach the right organization
Your chosen review interval To remember the setting between visits
Per-scan totals: repositories scanned, number of collaborators found, number flagged, cost estimates To show change over time. Counts only — no names
If you ask to hear about the paid plan: your organization login, and an email address only if you type one To contact you about that, and nothing else

What the app never stores

  • Collaborator names, logins, or email addresses
  • Repository names or contents
  • Source code, commits, issues, or pull requests
  • Access tokens beyond the hour-long installation token held in memory

What the app cannot do

It holds no write permissions. There is no code path that adds, changes, or removes access, creates or modifies repository content, or acts on your organization in any way. The capability does not exist in the application. The source is public if you would rather verify that than take our word for it.

Third parties

Two, and no others: GitHub, which is where the data comes from, and Fly.io, which hosts the application and stores its database. There is no analytics, no tracking, no advertising, and no data is sold or shared with anyone.

Retention and deletion

Uninstalling the app immediately stops all access — the installation token is revoked by GitHub and no further data can be read. The stored records described above are kept so that reinstalling does not lose your settings.

To have those records deleted, open an issue at the project repository and say so. There is no automated flow for it yet; it is done by hand, and it is done.

Changes

If this policy changes materially, the change lands in the public repository with the rest of the source, where its history is visible.

Contact

Open an issue for anything — questions, deletion requests, or a security concern.
